# M4 Data Provenance

## Generated data

The WAV files in `virtual_mics/` are generated by `audio_pipeline/signals.py` using deterministic NumPy random seeds. They are synthetic validation signals and must not be described as field recordings.

## Software results

`results/audio_metrics.csv` and `results/block_latency_benchmark.csv` are generated by the included scripts. Processing-time values depend on the machine used to execute the benchmark.

## External specifications

Hardware-interface specifications are summarized from manufacturer documentation in `AUDIO_INTERFACE_SELECTION.md`. External specifications are not physical measurements performed by SilentVox.
