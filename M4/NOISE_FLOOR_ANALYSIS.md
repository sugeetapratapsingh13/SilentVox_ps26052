# Noise Floor and SNR Analysis

## Scope

This document reports reproducible **digital test-stream results** generated by the M4 software. It does not report microphone SNR, microphone self-noise, physical ADC noise, headset noise floor, or acoustic end-to-end SNR.

## Definitions

For a signal `s` and noise reference `n`:

`RMS(x) = sqrt(mean(x^2))`

`SNR(dB) = 20 log10(RMS(signal) / RMS(noise))`

## Provenance

The current virtual test files are generated by `audio_pipeline/signals.py` and are therefore **synthetic/generated digital streams**. They are standardized to 16 kHz and materialized as 16-bit PCM WAV files.

`analysis/run_analysis.py` generates:

- REF;
- ERR;
- SPCH;
- clean speech;
- stationary noise;
- rotor-like noise;
- impulsive noise;
- speech+noise.

## Actual numerical result

The reproducible results are written to `results/audio_metrics.csv`. The speech-plus-noise condition defines:

- **signal** = `speech_clean.wav`;
- **noise** = `speech_plus_noise.wav - speech_clean.wav`.

The resulting SNR is recorded in the `snr_db` field for the `speech_plus_noise_condition` row, and the corresponding noise RMS is recorded in `noise_rms`.

This is a **digital test-stream SNR**. It must not be described as microphone SNR.

## Noise floor versus SNR

A noise floor is a level/measurement of the noise component under a stated measurement condition. SNR is a ratio between a defined signal and a defined noise component. They are reported separately in the generated evidence.

## Units

- Internal samples: normalized float32 approximately in `[-1, +1]`.
- Peak level: can be expressed as dBFS using the digital full-scale convention.
- Current WAV boundary: signed 16-bit PCM.
- No acoustic SPL calibration is claimed.
