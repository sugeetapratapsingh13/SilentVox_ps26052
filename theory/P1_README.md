# Person 1 — ANC Theory + Mathematics

## Purpose

This folder contains the theoretical and mathematical foundation for the SilentVox ANC work.

## Files

- `ANC_THEORY.md` — ANC concepts, architectures, paths, adaptive filtering, LMS/NLMS/FxLMS concepts.
- `ANC_EQUATIONS.md` — mathematical definitions and derivations.
- `GLOSSARY.md` — project terminology.
- `ANC_BLOCK_DIAGRAMS/` — block-diagram source files and exported diagrams.

## Ownership

Person 1 owns the theory and mathematical specification.

Person 3 implements LMS/NLMS.

Person 4 performs controlled simulation/noise experiments.

Person 5 implements FxLMS and secondary-path modelling.

Person 6 performs parameter sweeps and real-time benchmarking.

## Important boundary

This documentation does not select a winning algorithm or final parameter values. Those must be determined from experimental evidence.
