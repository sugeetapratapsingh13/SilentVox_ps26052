# ANC Glossary — SilentVox

| Term | Definition |
|---|---|
| ANC | Active Noise Control; reduction of unwanted sound using a generated control/anti-noise signal. |
| Active Noise Control | A signal-processing approach that generates sound intended to reduce unwanted acoustic noise through interference. |
| Reference signal | A signal correlated with the unwanted disturbance and used by an adaptive controller. |
| Desired/disturbance signal | The unwanted signal that the simplified adaptive model seeks to reduce. |
| Anti-noise | Controller-generated signal intended to reduce the disturbance at the target location. |
| Control signal | Signal generated by the ANC controller and sent toward the actuator/speaker. |
| Error signal | Residual signal used to evaluate cancellation and adapt the filter. |
| Residual noise | Unwanted signal remaining after cancellation. |
| Primary path | Acoustic path followed by the unwanted disturbance toward the cancellation/error location. |
| Secondary path | Path followed by generated anti-noise from the controller/actuator to the error sensor. |
| Adaptive filter | A filter whose coefficients change according to an adaptation rule. |
| FIR | Finite Impulse Response filter; a filter whose output is a finite weighted sum of present/past input samples. |
| LMS | Least Mean Squares adaptive algorithm based on a stochastic-gradient update. |
| NLMS | Normalized Least Mean Squares; LMS with normalization based on current input-vector energy. |
| FxLMS | Filtered-x LMS; an ANC algorithm that accounts for the secondary path by filtering the reference through a secondary-path estimate. |
| FxNLMS | Filtered-x NLMS; combines filtered-reference adaptation with NLMS-style normalization. |
| Step size (mu) | Parameter controlling the magnitude of adaptive coefficient updates. |
| Filter length (L) | Number of coefficients/taps in the adaptive FIR filter. |
| Epsilon | Small positive regularization value used in NLMS normalization. |
| Sampling rate | Number of samples processed/acquired per second. |
| Cost function | Quantity minimized by the adaptive algorithm; for the baseline LMS derivation, `J(n)=1/2 e^2(n)`. |
| Gradient | Vector of partial derivatives describing the direction of greatest local increase of a scalar function. |
| Gradient descent | Optimization method that updates parameters opposite the gradient. |
| Convergence | Process by which an adaptive algorithm approaches a useful steady-state solution. |
| Stability | Property of an adaptive process remaining bounded rather than diverging. |
| Misadjustment | Excess steady-state mean-square error associated with adaptive operation relative to the minimum achievable error. |
| MSE | Mean Squared Error; average of squared error values over a defined set/window. |
| Autocorrelation matrix | Matrix describing second-order statistical relationships among elements of the reference vector. |
| `P(z)` | Symbolic representation of the primary acoustic path/system. |
| `S(z)` | Symbolic representation of the secondary acoustic path/system. |
| `S_hat(z)` | Estimated/modelled secondary path used by FxLMS. |
| Filtered-x | Reference signal after filtering through the secondary-path estimate. |
| Reference microphone | Sensor providing the reference signal in a feedforward ANC system. |
| Error microphone | Sensor measuring residual sound/error at the target location. |
| Acoustic path | Physical propagation/transfer route taken by an acoustic signal. |
| Convergence time | Time or number of samples required to reach a specified convergence criterion. |
| Latency | Time delay between input acquisition and relevant output/control action. |
